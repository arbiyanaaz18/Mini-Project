# Team Contributions and Collaborative Development

## 1. Project Overview

**Project Name:** Disaster Resource Tracker

The project was developed collaboratively by dividing responsibilities among four team members. Each member was responsible for a specific component, and all components were integrated to develop the complete application.

## 2. Individual Responsibilities

| Team Member | Assigned Component | Responsibilities |
|---|---|---|
| Ankita Muradi | Database Management (DBMS) | Database design, schema creation, ER diagram, normalization, database integration and data management. |

## 3. Component Integration

- Database connected with backend services.
- Backend APIs integrated with the React frontend.
- Datasets processed and integrated into the application.
- Algorithms and data structures support resource management and request prioritization.
- All components combined to form the Disaster Resource Tracker.

## 4. Testing and Verification

- Automated backend tests were executed.
- 81 tests passed in the verified test run.
- Database operations were verified.
- Key-value store and caching functionality were tested.
- Frontend and backend integration was checked.

## 5. Collaborative Development

Each team member contributed to their assigned component. The individual components were integrated and tested to ensure the complete system worked together.

## 6. Conclusion

The Disaster Resource Tracker was developed through collaborative work, component-wise responsibilities and system integration. The team focused on implementation, testing, debugging and overall project readiness.
